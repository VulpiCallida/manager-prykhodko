# Требования к сайту — версия 0.2

## Подтверждено

- Одностраничный сайт-резюме, размещение на GitHub Pages.
- Референс: https://ux-korchagin.ru/#/
- Фон белый, основной текст чёрный. Акцентные цвета — изумрудный и синий, с их оттенками. Конкретные оттенки выбираются при дизайне с проверкой контраста.
- Одна фотография: исходный файл photo1.png в корне проекта.
- Первый экран: фото, имя, приветствие, краткое описание специализации, контакты, статус доступности к предложениям, удалённый формат работы. Точная формулировка статуса уточняется.
- Далее опыт работы: компания с логотипом, должность, даты и описание. Текст опыта переносится из актуального резюме без переписывания и сокращения.
- После опыта — пет-проекты. Кейсы и FAQ опциональны, появляются при наличии материалов.
- Закреплённая верхняя панель: фото и имя возвращают наверх.
- Слева на десктопе — оглавление с подсветкой текущего раздела и плавным переходом по нажатию.
- Справа внизу — кнопка возврата наверх после ухода с первого экрана.
- Адаптация для десктопа и мобильных устройств.
- Внутренних отдельных страниц нет. Контакты кликабельны.

## Предлагаемые решения

- На мобильных — раскрывающееся меню «Разделы» вместо бокового оглавления. Выбор закрывает меню и прокручивает к разделу.
- Кейсы раскрываются внутри страницы; FAQ — список раскрывающихся вопросов.
- Контакты повторяются в конце страницы.
- Анимации сдержанные: появление блоков, состояния кнопок, раскрытие подробностей. Учитывается настройка уменьшения движения.
- HTML + CSS + JavaScript, без сервера и базы данных. Основной текст доступен без JavaScript.
- Публикация только site через GitHub Actions; пути совместимы с размещением в подпапке GitHub Pages.

## Проверка готовности

Сверка текста с резюме; работа ссылок, оглавления и обеих кнопок возврата; отсутствие перекрытий закреплёнными элементами и горизонтальной прокрутки; проверка ширин 360, 390, 768, 1024, 1440 пикселей; доступность с клавиатуры; читаемый контраст; название страницы, описание, favicon и превью ссылки; проверка опубликованной версии.
