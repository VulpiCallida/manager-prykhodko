# Первая версия страницы

Собрана в site. Для публикации: GitHub Desktop → Commit to main → Push origin.

Содержимое: первый экран с фото, четыре места работы, два пет-проекта, навыки и образование, контакты. Формулировки 22 пунктов опыта совпадают с Google Docs на момент сборки. PDF служит исходным материалом и не публикуется.

Проверено: ширины 360, 390, 768, 1024, 1440; отсутствие горизонтального переполнения; мобильное меню и закрытие после выбора; подсветка разделов; раскрытие проекта; возврат наверх; локальные ресурсы и якоря; синтаксис JavaScript; отсутствие ошибок в консоли браузера.

Отдельные кейсы и FAQ пока не выведены: материалов для них нет. Пет-проекты пока без скриншотов. Приветствие на первом экране — редакционный вариант для просмотра.

Исходники — materials (не входят в Git), публичные оптимизированные изображения — site/assets/images. Размещённые тексты редактируются в site/index.html; сайт не читает Markdown из materials автоматически.
