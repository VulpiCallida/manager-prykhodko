## Куда добавлять материалы

- materials/resume — исходное резюме PDF. На сайт не публикуется.
- materials/texts — заметки, описания проектов, кейсов и ответы FAQ.
- materials/images/profile — оригиналы фотографий.
- materials/images/companies — логотипы компаний, желательно SVG или PNG с прозрачностью.
- materials/images/projects — изображения пет-проектов; отдельная подпапка для каждого проекта.
- materials/images/cases — изображения кейсов; отдельная подпапка для каждого кейса.
- materials/images/social — необязательные материалы для превью ссылки в мессенджерах.

Названия файлов могут быть любыми понятными. Для скриншотов удобно добавлять номер и пояснение: 01-main-screen.png. К каждому проекту можно положить описание.txt рядом с изображениями. Необязательно заранее готовить обложки или подгонять размеры — для сайта подготовим отдельные копии.

Существующие photo1.png и PDF не перемещены. После распаковки их можно оставить в корне до следующего этапа либо перенести в соответствующие папки materials.

## Структура реализации

site — только опубликованные файлы сайта. В дальнейшем здесь появится index.html.
site/assets/css — стили.
site/assets/js — навигация и интерактивность.
site/assets/images — оптимизированные копии выбранных изображений.
docs — требования и решения по проекту.
materials — локальные исходники, исключённые из Git по умолчанию.

GitHub Pages будет получать только содержимое site через GitHub Actions. Настройка публикации будет создана вместе с сайтом. Публиковать весь корень проекта нельзя: там могут оставаться исходные материалы.

Пустые .gitkeep нужны только для сохранения структуры папок в Git.
